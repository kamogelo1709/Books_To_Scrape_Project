# Books To Scrape Project
Richfield Graduate Institute - Python Data Science Project

## GitHub Repository Link
https://github.com/kamogelo1709/Books_To_Scrape_Project

## Project Overview
This project scrapes 100 books from books.toscrape.com, performs data cleaning, visualization, and predicts book prices using Linear Regression.

## Files Included
- Books_To_Scrape_Project.ipynb - Main Jupyter notebook (Complete Pipeline - 100 marks)
- books_final_dataset.csv - Final dataset (100 books)
- books_final_dataset_cleaned.csv - Cleaned dataset

## Technologies Used
Python, Requests, BeautifulSoup, Pandas, Scikit-Learn, Matplotlib, Seaborn

## How to Run
pip install requests beautifulsoup4 pandas scikit-learn matplotlib seaborn jupyter
jupyter notebook Books_To_Scrape_Project.ipynb

## Results
Machine Learning Model: RMSE 12.44, R2 Score 0.04
